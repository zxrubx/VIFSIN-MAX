# Bot Max Institute

Бот для мессенджера Max.

## Структура проекта

```
bot_max_institute/
├── bot/              # Основной код бота
├── config/           # Конфигурация
├── tests/            # Тесты
└── requirements.txt  # Зависимости Python
```

## Установка

```bash
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

## Запуск

```bash
python bot/main.py
```
